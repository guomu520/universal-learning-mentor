# 🛡️ Universal Learning Mentor (通用反焦虑学习教练)

> **“我们买的不是课，是缓解焦虑的安慰剂；我们收藏的不是教程，是永远不会打开的赛博骨灰盒。”**

这是一个基于四大历史人物心智模型（苏格拉底、达尔文、老子、曾国藩）深度蒸馏而成的 **AI Agent Skill**。

它**不是**一个用来陪你闲聊的机器人，而是一个**极其克制、甚至有点冷酷的私人教练**。它用强制性的逻辑协议，帮你砍掉多余的信息，只保留每天 10 分钟的最小行动，专治“想学 AI / 英语 / 编程，但永远停留在找教程阶段”的重度拖延症。

## 🧠 它是怎么工作的？（四重认知流水线）
1. **摸底（苏格拉底）**：不追问"你想学什么"——小白说不清目标，但说得清烦心事。把抽象的"想学 AI"翻译成"你每天重复做、最烦的那件事"。焦虑到说不出痛点时，直接切到具体动作，不越问越慌。
2. **处方（达尔文 + 老子，一次给完）**：无情指出 2 个"绝对不要碰"的陷阱，只留 1 个用户**已经装好**的工具，再给一个 15 分钟就能产出成品的微动作和可直接复制的启动模板。零安装、零注册、零理论。
3. **日课卡**：处方末尾附一张 3 行小卡片，用户复制保存，下次直接贴回来即可续上。换设备、清上下文、断更两周都不怕——这才是"半途而废"的真正解药。
4. **复盘（曾国藩）**：第一句只问"做了没？把结果贴给我"。没做或断更，不追问原因，直接砍到 3 分钟重来，当作第一天；效果差只改模板里的一句话；连续 3 次完成就结业，不让用户产生依赖。

> 全局护栏：不给路线图、书单、课表；不解释原理和黑话；全篇只出现 1 个工具；不推荐要付费/下载/注册/翻墙的工具；不夸奖、不说"每天坚持"。

## 📦 如何安装？
目前支持所有能够自定义 Prompt 或 System Instructions 的 AI 客户端（如 ChatGPT, Claude, Kimi, 豆包）以及 Agent 工具（Codex, Cursor, Coze 等）。

**方法一：直接在网页端使用（最简单）**
1. 复制本仓库 `SKILL.md` 中的全部内容。
2. 粘贴到你常用 AI 平台的“系统提示词（System Prompt）”或“自定义指令”中。
3. 发送一句：“我想学点新东西”，开始受虐（划掉）成长。

**方法二：在 Cursor / Codex 等本地工具中使用**
1. 将本仓库克隆到本地。
2. 将 `SKILL.md` 放入你的 `~/.codex/skills/` 或 Cursor 的 Rules 目录下。
3. 在对话框输入 `$universal-learning-mentor` 召唤。
