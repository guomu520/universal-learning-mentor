# 🛡️ Universal Learning Mentor (通用反焦虑学习教练)

> **“我们买的不是课，是缓解焦虑的安慰剂；我们收藏的不是教程，是永远不会打开的赛博骨灰盒。”**

这是一个基于四大历史人物心智模型（苏格拉底、达尔文、老子、曾国藩）深度蒸馏而成的 **AI Agent Skill**。

它**不是**一个用来陪你闲聊的机器人，而是一个**极其克制、甚至有点冷酷的私人教练**。它用强制性的逻辑协议，帮你砍掉多余的信息，只保留每天 10 分钟的最小行动，专治“想学 AI / 英语 / 编程，但永远停留在找教程阶段”的重度拖延症。

## 🧠 它是怎么工作的？（四重认知流水线）
1. **摸底（苏格拉底）**：不追问"你想学什么"——小白说不清目标，但说得清烦心事。把抽象的"想学 AI"翻译成"你每天重复做、最烦的那件事"。焦虑到说不出痛点时，直接切到具体动作，不越问越慌。
2. **处方（达尔文 + 老子，一次给完）**：无情指出 2 个"绝对不要碰"的陷阱，只留 1 个用户**已经装好**的工具，再给一个 15 分钟就能产出成品的微动作和可直接复制的启动模板。零安装、零注册、零理论。
3. **日课卡 + 状态文件**：在 WorkBuddy 这类能读写本地文件的环境里，教练会**自己把日课卡写进 `state/日课卡.md`**，下次对话自动读取、直接复盘——用户什么都不用保存。纯网页版自动降级为文本卡，贴回来即可续上。换设备、清上下文、断更两周都不怕。
4. **复盘（曾国藩）**：第一句只问"做了没？把结果贴给我"。没做或断更，不追问原因，直接砍到 3 分钟重来，当作第一天；效果差只改模板里的一句话；连续 3 次完成就结业，不让用户产生依赖。

> 全局护栏：不给路线图、书单、课表；不解释原理和黑话；全篇只出现 1 个工具；不推荐要付费/下载/注册/翻墙的工具；不夸奖、不说"每天坚持"。

## 🚀 真正用起来（30 秒）

**WorkBuddy（推荐，闭环完整）**

```bash
git clone https://github.com/guomu520/universal-learning-mentor.git \
  ~/.workbuddy/skills/universal-learning-mentor
cp ~/.workbuddy/skills/universal-learning-mentor/state/日课卡.example.md \
   ~/.workbuddy/skills/universal-learning-mentor/state/日课卡.md
```

然后直接说一句：**"我想学 AI，但不知道从哪开始"**。技能会自动命中，教练自己读写状态文件，你不用保存任何东西。

**其它能自定义提示词的平台（ChatGPT / Claude / Kimi / 豆包 / Cursor / Coze）**

1. 复制 `SKILL.md` 全文，粘到「系统提示词 / 自定义指令 / Rules」。
2. 发一句"我想学点新东西"。
3. 纯网页版没有文件读写能力，把教练给的日课卡**贴回来**即可续上复盘。

> 两种模式的差别只有一处：**状态由谁记**。协议、四重认知流水线、全部护栏完全一致。

## ✅ 验收（可复现，不靠感觉）

```bash
python3 scripts/check_skill.py
```

脚本会检查 frontmatter、必需章节、硬规则、历史规则冲突回归，并逐段验收 `tests/sample-transcript.md` 里按协议生成的真实输出（问号数、进度标记、工具数、陷阱数、字数预算、禁用表达）。当前 **104/104 通过**，实测处方叙述 210 字 / 上限 260 字，预算可行。
