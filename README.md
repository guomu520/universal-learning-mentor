# 🛡️ Universal Learning Mentor (通用反焦虑学习教练)

> **“我们买的不是课，是缓解焦虑的安慰剂；我们收藏的不是教程，是永远不会打开的赛博骨灰盒。”**

这是一个基于四大历史人物心智模型（苏格拉底、达尔文、老子、曾国藩）深度蒸馏而成的 **AI Agent Skill**。

它**不是**一个用来陪你闲聊的机器人，而是一个**极其克制、甚至有点冷酷的私人教练**。它用强制性的逻辑协议，帮你砍掉多余的信息，只保留每天 10 分钟的最小行动，专治“想学 AI / 英语 / 编程，但永远停留在找教程阶段”的重度拖延症。

## 🧠 它是怎么工作的？（四重认知流水线）
1. **摸底（苏格拉底）**：不追问"你想学什么"——小白说不清目标，但说得清烦心事。把"想学 AI"翻译成"每天最烦的那件事"，并问清他手上现成能打字对话的 App。**不显示"还差几步"这类进度标记**。
2. **处方（达尔文 + 老子，一次给完）**：2 个"绝对不要碰"的陷阱，只留 1 个**用户自己报出来**的工具；给一个 15 分钟能产出成品的微动作，外加两块可直接复制的内容——贴给那个 App 的话（示例填好、无占位符）和「照着点」操作步（把长按、复制、切应用、粘贴、发送拆开）。零安装、零注册、零理论。
3. **日课卡 + 状态文件**：能读写文件的环境里教练自己记状态，下次对话直接复盘；纯网页版**不要求用户保存整张卡**，回钩自带任务上下文（发「周报助理，做了」或「我断了」）；**只有带回归信号才进复盘，新用户第一句话一律走开场白**。
4. **复盘（曾国藩）**：第一句只问"做了没"。没做或断更，不追问原因，砍到 3 分钟重来；效果差只改一句话；**断更后能自己回来重开**才结业，且结业不关门，留下「我断了」这个暗号。

> 全局护栏：不给路线图、书单、课表；不解释原理和黑话；全篇只出现 1 个工具；不推荐要付费/下载/注册/翻墙的工具；不夸奖、不说"每天坚持"；**不预判用户会放弃、不用内部术语、成品里不留占位符**。若用户报的 App 里没有 AI 入口，第一步就改在当前对话里做，不安排安装或跨应用搬运。

## 🚀 真正用起来（30 秒）

**WorkBuddy（推荐，闭环完整）**

```bash
git clone https://github.com/guomu520/universal-learning-mentor.git \
  ~/.workbuddy/skills/universal-learning-mentor
cp ~/.workbuddy/skills/universal-learning-mentor/state/日课卡.example.md \
   ~/.workbuddy/skills/universal-learning-mentor/state/日课卡.md
```

然后直接说一句：**"我想学 AI，但不知道从哪开始"**。技能会自动命中，教练自己读写状态文件，你不用保存任何东西。

**其它智能体（豆包 / Codex / Claude Code / Cursor / ChatGPT / Coze …）**

⚠️ **不要把 `SKILL.md` 整段粘到网页平台**：它含 YAML frontmatter、本地文件读写指令和内部校准锚点，对纯聊天平台是噪音，豆包「设定描述」也塞不下 3000+ 字。用 `dist/` 里的自动生成版：

| 平台 | 用哪个文件 |
|---|---|
| 豆包智能体 | **首选 `dist/prompt-plain.md`**（完整版）；账号若确有短字数限制再用 `dist/prompt-mini.md`（1165 字）。记得把「最大输出字数」从默认 500 调到 1000+ |
| ChatGPT / Claude 网页 / Kimi / Coze | `dist/prompt-plain.md` |
| Codex / Claude Code | 原生安装 `SKILL.md` → 见 `dist/PLATFORMS.md` |
| Cursor | `dist/cursor-rule.mdc` 或 `dist/AGENTS.md` |

完整路径、逐平台步骤和生效自检方法见 **[dist/PLATFORMS.md](dist/PLATFORMS.md)**。

> 两种模式的差别只有一处：**状态由谁记**。协议、四重认知流水线、全部护栏在所有平台完全一致。纯 Prompt 平台**不需要用户保存或贴回日课卡**——首句带回归信号才进复盘，否则走开场白；有状态文件时以日期为准。
>
> 查证结论：豆包「设定描述」的 300–600 字是社区建议，不是官方硬上限（官方只限制名称 12 字、输出字数默认 500 可调 2000）。独立评测证明 600 字版会删掉关键仲裁规则导致行为变形，所以 v4.x 把精简版扩到 1165 字，并把完整版列为首选。

**可选：让教练主动找你（监督闭环的最后一块）**

技能默认是被动的——你不回来，就没有下一次对话。在支持定时任务的宿主里加一条每日提醒即可补齐：每天固定时间读 `state/日课卡.md`，状态为「进行中」才发一条简短复盘，无卡或已结业不打扰。WorkBuddy 里的配置示例：

```text
名称：学习教练 · 每晚日课复盘
频率：FREQ=DAILY;BYHOUR=21;BYMINUTE=0
任务：读状态文件；进行中→按阶段四发一条 ≤120 字复盘（断更则给 3 分钟降维版）；
      状态为「无」或「已结业」→ 不输出任何内容，不打扰。
```

⚠️ 定时任务只做提醒，不要代用户改状态文件——状态由对话中的教练在复盘后更新。

## ✅ 验收（可复现，不靠感觉）

```bash
python3 scripts/build_dist.py   # 重新生成 dist/，精简版超 1300 字会报错
python3 scripts/check_skill.py  # 验收协议、dist 一致性、真实输出
```

脚本会检查 frontmatter、必需章节、硬规则、历史规则冲突回归、`dist/` 各平台版本与协议的一致性、精简版是否补回关键仲裁，并逐段验收 `tests/sample-transcript.md` 里按协议生成的真实输出（问号数、禁用步数标记、工具数、陷阱数、字数预算、围栏内模板才不计字数、占位符泄漏、结业暗号）。当前 **227/227 通过**；另含演示文档漂移检查（防止改协议时 demo 停在旧版）。

想验真实效果而不是验文档，用同一套双盲方法：让一个没看过任何 demo 的独立模型只拿 `SKILL.md` 现场跑一轮对话，把输出喂给 `--transcript=PATH` 交叉验收；再让另一个独立模型从真小白视角挑毛病。

## 📁 目录

```text
SKILL.md                        核心协议（单一数据源，v4.1）
scripts/build_dist.py           从 SKILL.md 生成各平台适配文件
scripts/check_skill.py          验收器
dist/prompt-plain.md            纯提示词版（ChatGPT / Claude / Kimi / Coze）
dist/prompt-mini.md             1165 字精简版（仅在确有短字数限制时用）
dist/cursor-rule.mdc            Cursor Rule（Apply Intelligently）
dist/AGENTS.md                  Codex / Cursor / Copilot 通用
dist/PLATFORMS.md               兼容性矩阵与逐平台安装步骤
state/日课卡.example.md         状态文件字段说明
state/日课卡.md                 运行时状态（.gitignore 排除，不上传）
tests/sample-transcript.md      验收用真实对话记录
examples/                       两个完整演示
```

改完 `SKILL.md` 后跑 `python3 scripts/build_dist.py` 重新生成 `dist/`，不要手改。
