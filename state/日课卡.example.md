# 日课卡 · 状态文件模板

> 这是**给教练读的运行时状态**，不是给用户看的内容，请不要手动编辑。
> 教练会在给出处方时自动写入、复盘后自动更新。
> 真实文件名为 `state/日课卡.md`（已被 .gitignore 排除，不进仓库）。

```yaml
状态: 无            # 无 | 进行中 | 已结业
布置日期: ""
动作: ""
交付物: ""
启动模板: ""
完成次数: 0
结业日期: ""
```

## 字段含义

| 字段 | 用途 |
|---|---|
| 状态 | 教练判断"跳过开场白直接复盘"还是"重新摸底" |
| 布置日期 | 断更判断依据，不依赖用户自述 |
| 动作 / 交付物 / 启动模板 | 复盘时直接取用，不用用户重新描述 |
| 完成次数 | 满 3 次触发结业 |
| 结业日期 | 结业后不再加码，用户再来时重新开场 |

## 隐私约定

只存学习动作与结果。不写姓名、单位、账号、联系方式等任何身份信息。
