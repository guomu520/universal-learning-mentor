# 验收用真实对话记录

> 按 `SKILL.md` **v4.0** 协议逐条生成的教练输出，用来跑 `scripts/check_skill.py`。
> 场景：小白怕不学 AI 被淘汰 → 摸底（含问清现成的 App）→ 处方 → 断更回归 → 结业。
> 每个 `### Tn` 下方的 ```text 块是教练**实际输出原文**，脚本按阶段逐条校验硬规则。

---

**用户**：感觉不学 AI 就要被淘汰了，周围人都在用，可我连从哪儿开始都不知道。

### T1 | stage=摸底 | 焦虑分支，温和改问，不显示步数
```text
懂，这种被落下感最耗人。先别想学什么——你每天重复做、最烦的那件事是什么？
```

**用户**：每周五要写周报，把一周干的事凑成几条，特别烦。

### T2 | stage=摸底 | 只问一个能直接报名字的问题
```text
你平时打字发消息、或者想问点什么，用的是哪个？回一个名字就行。
```

**用户**：豆包，装过，只拿来问过天气。每天能挤出来的也就十来分钟。

### T3 | stage=处方 | 诊断+规划一次给完，介质锁死到用户报的 App
```text
每天只有 10 分钟，只想少烦一次。

绝对不要碰：① 从零讲起的长课——一集没看完就到了写周报的时候；② 一堆工具对比——挨个试完 10 分钟就没了。

只留一个：你刚才说的豆包。今天不装东西、不注册，现在用的就够。

今天只做这一件事：把这周做过的三件事打出来，连同下面整段话，发给你刚才说的那个豆包——

> 你是周报助理。把下面这 3 件事改写成 3 条周报要点，每条不超过 25 字，用动宾结构，不要加评价。内容如下：周一开了排班会；周二改了客户表格；周三跟了一次现场。

照着点：长按上面那段话 → 点复制 → 打开豆包 → 在输入框长按 → 点粘贴 → 点发送。

日课卡
- 今天只做：把 3 件事连同上面那段话发给豆包
- 做出来的是：3 条周报要点
- 明天这个点：发我一个字，做了 / 没做，不用保存任何东西
```

**（隔了 11 天）用户**：上次那个我一直没弄，是不是又失败了。

### T4 | stage=复盘 | 断更回归，不追问原因，≤120 字
```text
做了没？把结果贴给我。今天按第一天来，只花 3 分钟：随便打一句「今天整理了 3 件事」，连同原来那段话发过去就行，别的都不做。
```

**（断更后自己回来重开并完成）用户**：这次三条都对，我还顺手把整周的都丢进去了。

### T5 | stage=复盘 | 结业不关门，留下重启暗号，≤120 字
```text
你已经会自己把大事拆成小动作了。以后卡住，直接发「我断了」给我，我把动作砍到 3 分钟，不用解释。
```

---

## 这段记录验证了什么

| 目标 | 对应检查 |
|---|---|
| 打破信息过载 | 全程 1 个工具、0 个课程/书单/路线图、无概念解释 |
| 不靠猜介质 | 摸底直接问出用户手上现成的 App，处方锁死不换 |
| 最小成本启动 | 零安装零注册、贴给 App 的话填了具体示例、无占位符、「照着点」把复制粘贴拆成 6 个动作 |
| 焦虑用户不劝退 | 不追问「具体学习目标」，也不显示「还差几步」，改问每天最烦的一件事 |
| 不半途而废 | 回钩锚到「明天发一个字」，用户发来任何内容都触发复盘，不要求保存任何东西 |
| 不制造依赖 | 断更后自主重开才结业，且结业不关门，留下「我断了」暗号 |
| 规则可执行 | 摸底问号数、处方字数、陷阱数、围栏内模板不计字数，全部由脚本实测 |

## 运行方式

```bash
python3 scripts/check_skill.py
# 也可对任意现场输出做交叉验证：
python3 scripts/check_skill.py --transcript=/path/to/live_output.md --transcript-only
```
